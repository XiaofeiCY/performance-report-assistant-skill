# 调整企微智能总结默认提示词口径

## 背景

当前企微智能总结采集器的默认提示词聚焦在窄范围事项：

```text
总结 xxx 时间段内的聊天中涉及临时生产修数、生产数据处理、线上数据维护、业务方临时数据修正相关的事项。只列出真实发生的工作事项，按时间或事项分条。
```

用户反馈这个范围过窄，希望默认总结覆盖目标周期内实际做过的事情，并能识别“哪些人 / 哪些群找我”以及“我在每次对话中产出的工作内容”。

## 用户原始需求复述

用户希望把提示词中的旧口径：

```text
总结xxx时间段内的聊天中涉及临时生产修数、生产数据处理、线上数据维护、业务方临时数据修正相关的事项。只列出真实发生的工作事项，按时间或事项分条。
```

改为新口径：

```text
总结xxx时间段内做了哪些事情，哪些人哪些群找到我，梳理我在每次对话中产出的工作内容有什么
```

## 目标

调整企微智能总结默认提示词，使其默认采集范围从“临时修数 / 线上维护”扩展为“目标周期内的真实工作对话和工作产出梳理”。

调整后应能引导企微智能总结输出：

- 目标周期内做了哪些事情。
- 哪些人、哪些群找过我。
- 每次相关对话中，我实际产出的工作内容是什么。
- 只总结真实发生的工作事项，不编造、不把闲聊当工作成果。

## 范围

建议修改：

- `performance-report-assistant/scripts/collect_wecom_smart_summary.py`
  - 更新 `DEFAULT_PROMPT_BODY`。
  - 保持 `load_prompt(args)` 的周期拼接逻辑可读、自然。
- `performance-report-assistant/references/intake-questions.md`
  - 更新企微智能总结采访示例，避免继续把“临时生产修数”作为默认主要方向。

可按需要补充轻量说明或测试，但不要扩大到自动化流程重构。

## 不做事项

- 不运行全自动企微实机测试。
- 不改企微窗口识别、点击、OCR、复制、指纹校验等自动化状态机逻辑。
- 不恢复 `CLAUDE.md` 或 `AGENT.md`。
- 不把某一次用户模板或周报草稿固化为全局模板。
- 不引入新的外部依赖。

## 建议执行步骤

1. 定位旧提示词：

```powershell
rg -n "临时生产修数|生产数据处理|线上数据维护|业务方临时数据修正|只列出真实发生" .
```

2. 修改 `DEFAULT_PROMPT_BODY`，建议保留“真实发生、不编造、按时间或事项分条”的约束，并加入新口径要素。

可参考方向：

```text
做了哪些事情，哪些人、哪些群找到我，梳理我在每次相关对话中产出的工作内容。只列出真实发生的工作事项，不编造，不把闲聊或无明确产出的对话写成工作成果；按时间或事项分条。
```

注意当前 `load_prompt(args)` 会生成：

```text
总结 {period} 期间{DEFAULT_PROMPT_BODY}
```

因此 `DEFAULT_PROMPT_BODY` 开头要能自然接在“总结 2026-xx-xx 至 2026-xx-xx 期间”之后。

3. 更新 `performance-report-assistant/references/intake-questions.md` 中企微采集内容示例，让默认示例更贴近：

```text
目标周期内做了哪些事、哪些人/哪些群找过我、每次对话中我产出的工作内容、跨部门协调、风险跟进等。
```

4. 运行静态验证和提示词生成验证。

## 交付物

- 更新后的 `DEFAULT_PROMPT_BODY`。
- 更新后的企微智能总结采访示例。
- 验证命令结果说明。

## 测试要求

必须至少执行：

```powershell
python .\performance-report-assistant\scripts\collect_wecom_smart_summary.py --prompt-only --period "2026-06-29..2026-07-03"
```

检查输出提示词是否包含：

- `做了哪些事情`
- `哪些人`
- `哪些群`
- `每次`
- `产出的工作内容`

并确认输出提示词不再包含旧窄范围关键词：

- `临时生产修数`
- `生产数据处理`
- `线上数据维护`
- `业务方临时数据修正`

建议再执行：

```powershell
rg -n "临时生产修数|生产数据处理|线上数据维护|业务方临时数据修正|只列出真实发生" performance-report-assistant
```

如果 `只列出真实发生` 被保留为防编造约束，可以保留；但旧窄范围关键词不应继续出现在默认提示词或默认采访示例中。

## 验收标准

- `--prompt-only` 生成的新默认提示词符合用户新口径。
- 周期拼接仍然自然，例如：

```text
总结 2026-06-29 至 2026-07-03 期间做了哪些事情，哪些人、哪些群找到我，梳理我在每次相关对话中产出的工作内容...
```

- 默认提示词仍保留真实性约束，避免企微总结编造工作事项。
- 相关采访说明不再默认引导到“临时生产修数 / 线上维护”窄范围。
- 未触碰企微实机自动化流程和安全边界。

## 风险提醒

- 新口径比旧口径更宽，可能带来闲聊、无产出对话混入结果的风险；必须通过“只列出真实发生的工作事项 / 不把闲聊写成成果 / 有明确产出才记录”等约束降低噪声。
- 不要为了验证而运行全自动企微实机测试；本任务只需 `--prompt-only` 和静态搜索验证。
